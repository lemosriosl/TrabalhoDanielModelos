# Notebooks

- `exploracao/`: auditoria, graficos e STL, preferencialmente um notebook por base.
- `modelagem/`: experimentos e diagnosticos; logica reutilizavel deve ir para `src/`.
- `relatorio/`: arquivo-fonte que gera o HTML e o PDF finais.
- Feature engineering, por grupo: `trabalho/bases/grupoN/feature_engineering_baseN.ipynb`. O catalogo gerado fica em `catalogo_features_baseN.csv`, na mesma pasta.

Notebooks devem executar da primeira a ultima celula a partir da raiz do projeto e usar somente caminhos relativos.
