# Colaboracao

- `demandas.csv`: registro diario exigido pelo enunciado; uma demanda objetiva por linha.
- `handoffs/`: transferencia de contexto de trabalho incompleto.
- `prompts/`: registro de interacoes com IA que afetaram a entrega.
- `reviews/`: pareceres independentes sobre codigo, metodologia e texto.

Valores validos em `demandas.csv`:

- carga de trabalho: `Baixa`, `Media` ou `Alta`;
- complexidade: `Baixa`, `Media` ou `Alta`;
- status: `A fazer`, `Em andamento` ou `Concluida`.

Use datas no formato `AAAA-MM-DD` no repositorio. Na versao final do relatorio, elas podem ser exibidas como `dd/mm`.
