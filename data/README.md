# Dados

- `raw/base_01/` a `raw/base_05/`: versoes congeladas e imutaveis das cinco bases.
- `external/`: fontes auxiliares externas, com proveniencia documentada.
- `interim/`: resultados intermediarios de limpeza e regularizacao.
- `processed/`: matrizes finais de modelagem geradas de forma reproduzivel.

Cada pasta de base bruta deve conter o arquivo congelado e um arquivo de metadados/checksum gerado no congelamento. Consulte `rules/data.md`.
