# Registros de decisoes metodologicas

Use um ADR quando a escolha afetar mais de uma base, modelo ou etapa do pipeline. Exemplos: protocolo walk-forward, regra de disponibilidade de exogenas, tratamento de ausentes e formato dos resultados.

1. Copie `template.md` para `NNN-titulo-curto.md`.
2. Registre contexto, decisao, alternativas e consequencias.
3. Discuta com o grupo antes de marcar como `Aceita`.
4. Nao altere silenciosamente uma decisao aceita; crie um novo ADR que a substitua.
